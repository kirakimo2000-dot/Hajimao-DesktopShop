# ManagementWindow Override

- Layout: 1180×720 operations dashboard; 152 px persistent left navigation, flexible live scene center, 260 px alerts/tasks right rail, 56 px action bar.
- Density: 8 px rhythm, 40 px minimum desktop control height, 14–16 px readable body type. Use Segoe UI for Chinese body text; reserve monospace for money/time figures.
- Theme tokens: background `#17191D`, surface `#23262C`, elevated `#2D3138`, border `#444A55`, primary `#F2B84B`, success `#69C784`, warning `#E96C65`, text `#F2F2F2`, muted `#B8BDC7`.
- Product cards: always show name, textual stock state, stock/capacity, wholesale, price, profit, and labeled buttons. Never communicate low stock by color alone.
- Feedback: a persistent status line states the result and recovery path for failed restocking or pricing.
- Navigation: unavailable later-game modules remain visible with “后续开放” text rather than silently disappearing.
