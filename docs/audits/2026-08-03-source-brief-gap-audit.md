# 桌面原始需求差距审计（2026-08-03）

## 结论

当前 1.0.0 是一个完成度可靠的“第一阶段可玩 Demo”，不是原始桌面文件所描述的完整产品。技术底座、双窗口、基础经营闭环和存档已经成立；长期成长、深层经营、桌面交互细节、正式像素内容与商业街仍是后续主体。

新产品决策优先于原始文件中的速度建议：从 1.1.0 起，玩家不能暂停或切换 2x/4x，经营固定为现实 1x。1.0.0 的历史记录保持原样，旧存档在迁移后统一按 1x 继续。

## 不应误判为缺口的非目标

多人联机、完整开放城市、复杂物流、真实其他商店内部、商品生产、员工社交、股票金融系统和大量剧情均被原始文件明确排除在第一阶段之外。它们不是当前路线的欠债，也不进入 1.x 核心计划。

## 风险排序

1. **产品风险：挂机没有长期决策。** 先固定现实 1x，再补离线结算、需求因子与成长曲线。
2. **兼容风险：速度字段已进入 schema v1。** 必须提供 v1→v2 数据迁移，不能只删除枚举或隐藏按钮。
3. **玩法风险：调价不影响需求。** 当前价格只改变成交金额，会产生无代价抬价；应在成长系统前修正。
4. **内容风险：UI 入口多于实际系统。** 后续每个导航入口必须在对应领域能力完成后再启用。
5. **表现风险：正式素材为空。** 先稳定人物与货架尺寸规范，再批量制作 sprite，避免资产反复返工。

## 审计后的执行顺序

`固定现实时间与离线结算 → 需求/服务经营深度 → 店铺成长 → 采购自动化 → 员工系统 → 桌面交互与正式内容 → 商业街`
