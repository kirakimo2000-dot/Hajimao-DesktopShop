# Hajimao DesktopShop 桌面像素 UI 设计系统

## 产品语境

- Windows 桌面常驻的挂机增量经营游戏，不是全屏后台管理系统。
- 玩家每次打开经营页应先理解结果、原因和下一步，而不是阅读完整会计表。
- 深色暖调、清晰矩形边框和整数像素是主要视觉语言；不使用玻璃模糊、泛光、扫描线、联网字体或装饰性长动画。

## 设计令牌

- 背景分为 Background、Surface、SurfaceElevated 三层；靠色差和 2 像素边框建立层级，不依赖阴影。
- Primary 只用于当前导航、关键结论和唯一主操作；Success 与 Warning 必须同时配合文字表达。
- Text 对主要表面至少达到 7:1，TextMuted 至少达到 4.5:1；Focus 对背景至少达到 3:1。
- 数字继续使用本机等宽字体；正文使用 Segoe UI，避免为像素气质牺牲中文可读性。

## 布局与交互

- 采用 4/8 像素节奏；主要间距为 8、12、16、24。
- 所有主要导航和关键按钮至少 44 像素高，交互状态不能改变布局边界。
- 键盘焦点使用 2 像素高对比实线；Tab 顺序跟随视觉顺序。
- 管理页保持三入口：经营概览、经营策略、投资决策。右栏只把一个“下一步”作为首要内容。
- 内容可纵向滚动，不引入嵌套横向滚动；窗口最小 960×640 时主内容至少 440 像素宽，右栏至少 260 像素宽。

## 动效

- 桌面场景人物继续使用既有 24 帧表现；管理界面不新增装饰性动效。
- 未来微交互控制在 150～200ms，只改变颜色或透明度，并服从既有减少动态设置。

## v0.1.30 页面完成状态

- 首店选择：三种投资倾向采用同构卡片，固定按赚钱方式、风险、适合对象阅读；支持窗口缩放、纵向滚动和键盘操作。
- 桌面街区与店内页：保持既有动态横向长度和置顶行为；浮层、提示和 44 像素关键目标使用同一语义主题。
- 经营概览、策略与投资：当前导航、下一步和真实策略选中态清楚；主要内容仅纵向滚动，小字不低于 12 像素。
- 后续 UI 修改由真实测试反馈或新玩法入口触发，不再通过增加图表、长教程、装饰动效和操作模块来制造复杂度。
