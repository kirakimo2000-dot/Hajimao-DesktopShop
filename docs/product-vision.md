# 产品定位

## 一句话定义

一款像素风的 Windows 桌面放置经营增量游戏：小店在桌面角落持续运转，玩家以短时、低频操作干预经营，并逐步从单店扩张为商业街。

## 核心体验

- **桌面共存**：玩家工作、聊天或浏览网页时，小店仍可见且继续经营。
- **观察优先**：顾客、员工、货架和排队直接在像素场景中表现，数据面板只做补充。
- **短时干预**：补货、调价、排班、促销等操作应在几十秒内完成。
- **离线/放置积累**：经营结果以可解释的批量模拟结算，不依赖窗口持续高帧率运行。
- **增量成长**：从单个角落便利店逐步解锁面积、货架、员工、商品和商业街。

## 时间与挂机原则

- 经营固定为现实 1x，不提供玩家可见的暂停、2x 或 4x。
- 程序运行时，小店按真实经过时间持续经营；低刷新率只能降低表现开销，不能减少经营进度。
- 程序关闭后按真实离开时间批量结算，且必须遵守库存、客流、员工和收银瓶颈，不能直接发放线性金币。
- 回归时展示收入、成本、销量、缺货和受阻原因，让玩家知道挂机结果为何产生。
- 长期效率来自更好的商品组合、补货策略、员工配置、自动化和店铺升级，而不是时间倍速。

## 视觉原则

- 像素素材按统一网格制作，并按整数倍缩放。
- 场景渲染关闭插值，避免像素边缘发糊。
- 小尺寸人物优先保证轮廓、动作和岗位可辨识。
- UI 可以采用像素边框、图标和字体点缀，但正文与数字必须清晰易读。
- 动画短促、有节奏，避免桌面常驻窗口持续吸引注意力。
- 暖色店内灯光与低饱和桌面背景形成区分，警告状态不只依赖颜色。

## 非目标

- 不做传统全屏、长时间占用注意力的经营游戏。
- 不在早期实现开放城市、多人联机、复杂物流或大量剧情。
- 不用 UI 表格替代可视化经营反馈。
