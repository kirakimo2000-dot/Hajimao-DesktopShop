# v0.1.0 项目基础阶段总结

日期：2026-08-03

## 已完成

- 建立 .NET 10 WPF solution、五个生产项目和两个测试项目。
- 建立明确的单向项目引用和模块目录。
- 集中管理编译选项与 NuGet 版本。
- 接入 MVVM、SkiaSharp、SQLite、Serilog 和测试基础设施。
- 建立产品定位、架构、技能、版本路线、更新日志和阶段报告规范。

## 验证证据

- `dotnet restore HajimaoDesktopShop.slnx --force`：成功。
- `dotnet build HajimaoDesktopShop.slnx --no-restore`：0 警告，0 错误。
- `dotnet list HajimaoDesktopShop.slnx package --vulnerable --include-transitive`：所有项目未发现易受攻击包。
- `dotnet test HajimaoDesktopShop.slnx --no-build`：退出码 0；当前尚未加入行为测试。

## 当前缺口

- 只有 WPF 模板窗口，尚未实现 DesktopShopWindow 与 ManagementWindow。

- 尚未确定像素素材的基础网格、人物尺寸和目标整数缩放倍数。
