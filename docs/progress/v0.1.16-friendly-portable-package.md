# Hajimao DesktopShop 0.1.16 单文件便携发布阶段报告

## 结果

0.1.16 将 Windows 便携 ZIP 从“解压后暴露约 502 个运行文件”改为“解压后只有一个 `Hajimao DesktopShop.exe`”。玩家无需判断哪个文件是入口，也不会再直接看到 .NET、WPF、SkiaSharp、SQLite 和项目程序集的 DLL。

游戏经营内容没有改变：固定现实 `1x`、在线/离线同一模拟管线、员工任务、24 帧人物表现、多店经营和 schema v6 均保持不变。本阶段只调整发布边界与用户看到的目录。

## 发布结构

### 便携版

- 使用 .NET 10 `PublishSingleFile` 生成单文件自包含程序。
- 使用 `IncludeAllContentForSelfExtract` 将 `Assets/Config/products.json`、原生依赖和运行时一并收入应用包。
- 使用 `EnableCompressionInSingleFile` 压缩程序集与运行时，避免单文件 EXE 膨胀到约 220 MB。
- 发布完成后把技术入口名 `HajimaoDesktopShop.Desktop.exe` 改为面向玩家的 `Hajimao DesktopShop.exe`。
- 发布脚本在压缩 ZIP 前断言便携目录恰好只有这个文件；任何额外 PDB、DLL、配置或目录都会让构建失败。

### MSI 安装版

- WiX 仍需要稳定的多文件安装负载，因此发布脚本新增独立 `installer-publish` staging 目录。
- MSI 继续使用 `HajimaoDesktopShop.Desktop.exe` 和完整自包含依赖，不复用便携单文件目录。
- 两种发布只在最终 release 清单中汇合；便携布局变化不会让安装器遗漏 SQLite 或原生 SkiaSharp 文件。

## 玩家使用方式

1. 解压 `HajimaoDesktopShop-0.1.16-win-x64-portable.zip`。
2. 双击唯一的 `Hajimao DesktopShop.exe`。
3. 存档和日志仍位于应用数据目录，不会写到 EXE 同级，也不会重新污染便携目录。

## 已知取舍

- 单文件程序首次在某台电脑启动时需要由 .NET 将内部运行组件解压到系统临时缓存，首次启动可能比后续启动略慢；应用目录仍保持单文件。
- `Compress-Archive` 会把生成时刻写入 ZIP 条目；相同源码重建时内部 EXE 字节可以一致，但 ZIP 外壳哈希仍会变化，因此每次正式发布都生成并随包提供独立清单和校验文件。
- 未进行代码签名，因此 Windows 可能继续显示未知发布者提示；签名和合规工作按用户要求后置。
- 本地环境未提升管理员权限，只执行 MSI 管理映像验证；GitHub Windows release gate 继续负责完整 per-machine 安装/卸载门禁。
