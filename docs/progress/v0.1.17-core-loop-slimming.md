# v0.1.17 核心循环瘦身

日期：2026-08-10

## 阶段结果

0.1.17 没有增加资源和新经营系统，而是把玩家角色从逐项维护的店员改回投资经营者。原七区管理窗口收敛为经营概览、经营策略和投资决策；日常运营继续由既有模块自动执行。

## 完成内容

- 全店定价定位：高周转、均衡、高毛利。
- 库存投入策略：精益、均衡、充足备货。
- 策略服务把玩家选择编译为既有调价与自动补货命令，不复制价格、容量、渠道或配送规则。
- 经营分析统一输出毛利率、现金续航和首要瓶颈，桌面层只负责中文呈现。
- 新店默认获得均衡自动补货策略；存档仍保存既有商品与采购状态，schema 保持 v6。
- 场景对象交互改为只读详情，快速采购、培训和排班等维护按钮不再暴露给玩家。
- 新手流程改为查看概览、选择策略、完成首单、实现盈利、首次投资和开设第二家店。
- 增加七天自动经营、策略结果分化及离线同管线的核心循环验收。

## 模块边界

- Domain 继续拥有价格、毛利、员工、店铺成长和经营结算规则。
- Application 新增纯策略计划、策略编译与经济分析，不依赖 WPF。
- Desktop 只组合三个玩家界面并调用 Application 服务，不持有经济公式。
- Infrastructure 与 Rendering 未引入新的玩法规则；存档和 24 帧人物表现契约不变。

## 玩家操作预算

- 高频判断：查看经营概览和瓶颈。
- 中频决策：选择整店定价与库存策略。
- 低频决策：招聘关键员工、扩建、升级货架或装修。
- 自动执行：逐次采购、补货、员工任务、排班维护、经营 Tick 与保存。

## 已知边界与下一步

- 0.1.17 已让经营循环可理解并能自动运转，但投资页还没有显示预期改善、现金压力和回收期，因此尚不称为 Playable Demo。
- 0.1.18 将统一员工、货架、扩建和装修的投资候选，提供成本、预期收益、回收期与投资前后对照。
- 0.1.19 负责目标、节奏、失败恢复和第二家店解锁平衡；0.1.20 才是通过陌生玩家盲测的 Playable Demo 1 节点。
