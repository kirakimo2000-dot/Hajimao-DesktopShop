# v0.1.20 Playable Demo Candidate 1

日期：2026-08-10

## 阶段结论

0.1.20 把 Hajimao DesktopShop 的已有经营模块接成第一条可供陌生玩家验证的完整挂机投资链：玩家只需观察经营、选择整店策略、配置资本并等待真实日结；日常采购、排班、员工任务和保存继续自动运行。版本没有新增商品、货币、速度、签到、重置或维护页面。

本阶段达到 **Playable Demo Candidate 1**，尚不宣称完成 Playable Demo 1。自动门禁可以证明链路可执行、数值可持续、在线/离线规则一致，但不能证明陌生玩家理解界面。正式晋级仍缺三轮真实陌生玩家首次接触与跨真实日回访记录。

## 玩家核心循环

`观察盈亏与瓶颈 → 选择整店策略 → 比较资本方向 → 执行投资 → 自动经营/离线挂机 → 查看下一份完整日结回报 → 再投资或扩店`

- 新手引导从六项长期任务收束为四步：观察、策略、首次投资、查看后续日结回报。
- 第一次投资前保留最近完整日结基线；下一份完整日结比较净利润、成交和流失，证据不足时明确等待，不制造综合评分。
- 第二家店、第三家店和完整街区继续由长期目标管理，不再为了结束教程而强制塞入首个游玩时段。
- 固定现实 `1x` 不变；挂机价值来自此前策略持续影响库存、客流、工资、队列和利润，而不是暂停、倍速或点击刷钱。

## 跨店资本配置

Application 新增只读 `CapitalAllocationAdvisor`，从所有已开店铺的既有投资组合中确定性派生最多三个方向：

1. **稳住弱店**：选择最近完整日结净利润最低的店，优先匹配其真实瓶颈和安全可执行候选。
2. **提高回报**：在其余候选中选择有正向保守收益和已知回本期的项目。
3. **扩张街区**：只显示下一家未开店，即使尚未满足等级或资金，也继续显示真实门槛。

跨店方案携带独立 `ExecutionStoreId`。Desktop 只格式化论点、店名和既有回报数据；写操作仍唯一调用 `StoreInvestmentService.Execute`，不会因为当前查看的店铺不同而误投。

## 离线回归解释

`ReturnBriefingService` 只读取现有 `OfflineSettlementResult` 和经营快照：

- 使用离线前后累计值计算现金、成交和净利润差额。
- 关注最近完整日结中净利润最低的店，并复用既有经营分析得到瓶颈。
- 弱店亏损时建议恢复，组合盈利且现金增长时提示比较再投资，其余情况只建议观察。
- 管理窗显示一张“本次回归”只读卡；没有领取、翻倍、第二次结算或额外状态。

## 长期成长与数值修复

- 扩建/货架/装修上限由 `4/5/5` 延长到 `8/9/9`；平方成本、能力变化、前置关系和存档字段保持不变，旧 `4/5/5` 档案恢复后可继续成长。
- 社区生活店开业成本从 `¥2,000.00` 调整为 `¥1,200.00`，让第三家店在长期资本积累中可达，同时仍需保留真实周转金和人员投入。
- 高毛利定位调整为参考售价 `108%`。过高溢价在三店阶段会因成交不足无法覆盖工资；新值与高周转、现金保全保持不同销量/毛利取舍，并能长期存活。
- 代表性长期策略在开店前同时预留两个经营周期和两名核心员工入职成本；新店优先形成至少两人、覆盖收银与补货能力的最小运营团队，候选池缺少所需能力时按正式刷新入口继续等待。
- 90 日门禁要求三条路线现金非负、工资支付失败为零、三家店全部开放、第 30 日后仍继续投资、第 90 日仍有可执行资本方向，且没有店铺全部封顶。

上述代表性策略只存在于测试项目，用于验证数值边界，不会进入正式游戏替玩家自动投资。

## 模块与持久化边界

- Domain 只延长既有 `StoreDevelopment` 上限；没有新增资源或第二套成长状态。
- Application 的资本顾问、回归简报、新手和长期目标均为不可变快照派生；经营写入继续走既有策略、投资、模拟和存档服务。
- Desktop 只持有文本、可见性和命令绑定，不拥有现金、员工、店铺或投资状态。
- schema 继续为 v6；新增功能不要求迁移存档结构。最近投资的既有可空字段继续负责跨会话比较。
- 人物仍统一使用 24 帧表现时间轴和压缩图集；商品、店铺主题、像素资源和音效范围本阶段冻结。

## 自动验收

- 四步新手闭环、资本顾问去重/跨店路由、离线回归分类和桌面绑定均有独立单元或契约测试。
- 生产端到端测试从默认新档出发，调用正式策略、投资、保存、离线恢复和开店入口，完成第一次投资回报、三次离线返回、第二家店和弱店投资；没有测试注资或复制生产公式。
- 1、7、30、90 日情景覆盖高周转、高毛利和现金保全，并验证重复运行确定、在线/离线推进等价、现金非负和工资支付成功。
- 最终完整解决方案、发布构建、资源、漏洞与发布物门禁结果在本版本发布完成后记录到下方“发布验证”。

## 真实盲测边界

协议位于 `docs/playtests/v0.1.20-blind-test-protocol.md`。三轮必须使用独立新存档和此前未接触项目的参与者，主持人只说“经营这家桌面小店”，记录 3 分钟盈亏解释、下一笔投资、首次回报、真实返回后的理解、口头求助和误操作。

当前没有填写参与者或通过结论。真实记录完成前，README、阶段报告和 GitHub Release 均只使用 Candidate 名称。
