# Hajimao DesktopShop 0.1.22 挂机体验收敛

## 本阶段结果

0.1.22 集中解决桌面挂机页和经营页的职责混乱，不增加新的玩法系统：

- 街区/店铺桌面挂机窗口永久置顶，经营管理窗口保持普通窗口层级。
- 拖动到任务栏附近后只吸附 Y 轴，保留玩家拖动后的 X 轴位置；街区扩张和页面切换也不再把窗口横向居中。
- 彻底移除离线收益。退出期间存档冻结，只有程序实际运行时的真实 Tick 才产生经营变化。
- 删除音效生成、播放、静音状态和相关入口；经营页只保留鼠标穿透桌面控制，桌面右键菜单同步保留该入口。
- 删除底部状态栏、显示/隐藏状态栏、全局状态文字和“现实 1x”展示文字，固定单速规则不变。
- 经营页右栏可纵向滚动；新手指引、长期目标和观察提示合并为一个动态“下一步”卡片，减少重复阅读和无效按钮。
- 左侧经营导航的选中指示与实际页面状态保持一致，“下一步”跳转后不会残留旧页面高亮。
- 清除已无调用方的逐对象维护动作视图模型和空商品目录接口；保留仍承担旧存档迁移的 schema v1～v5 类型。
- 新手引导删除运行 1 Tick 即完成的伪观察任务，改为策略、投资、回报三个真实动作；下一步按钮使用“选策略 / 看投资”等具体动词。

## 底层边界

- 版本：`0.1.22`
- 目标框架：`.NET 10`
- 存档 schema：`v6`，未迁移也未破坏现有存档。
- 模拟仍使用固定真实时间 Tick，不提供倍速。
- 本次删除的是退出期间补算链路，不改变程序运行时的工资、库存、顾客、销售和成长计算。

## 尚需人工确认

透明、无任务栏按钮的桌面窗口行为无法只靠无界面测试完全确认。下一步应在真实 Windows 桌面完成一次短验收：

1. 将挂机页拖到不同 X 轴位置，靠近任务栏确认只发生垂直吸附。
2. 同时打开经营页和其他普通应用，确认只有挂机页始终置顶。
3. 缩小经营页高度，确认右栏可以滚到最底部且“下一步”始终明确。
4. 退出一段时间后重新启动，确认现金、库存和游戏时间均未离线增长。

完成上述验收后，再进入陌生玩家盲测；在拿到三份真实反馈前不升级为正式 Playable Demo 1。
