# Hajimao DesktopShop 0.1.24 内容与事件底层

## 本阶段完成

- 新增 32 个正式员工档案，覆盖 16 个地区标签、六种岗位和多组效率/工资偏差；候选仍由后台确定性地产生三人。
- 员工身份跟随候选、雇佣、员工快照与存档完整保留；既有存档自动使用 `legacy` 档案 ID，无需提升 schema。
- 新增 32 个市场事件，覆盖街区、门店、商品品类、员工和全局范围；每个事件都有明确持续时间、冷却和整数修正量。
- 实现确定性事件调度：事件只随正在运行的模拟分钟推进，不做离线追赶；同一存档恢复后继续相同时间线。
- 事件通过现有需求模型影响客流、购买概率和商品货架权重，不允许事件文案直接改变现金。
- 正式桌面启动会加载员工/事件资源，但本阶段不增加事件 UI、按钮或新管理负担。

## 小而美边界

- 复用现有商店与商品目录，没有为内容数量重复迁移稳定配置。
- 候选池固定三人；事件选项最多两个，同时最多存在一个待决策事件。
- 采购成本和员工效率事件效果已经有数据合同，本阶段暂不跨模块改采购账本与员工领域对象，避免未经完整经济测试的半接入。
- 真实店名仍只使用文字，人物资源继续引用组合外观键；本阶段没有新增逐人物大图。
