# Hajimao DesktopShop 0.1.28 具体店铺决策摘要

## 本阶段完成

- 具体店铺概览改为三段式：先看本店表现，再看主要原因，最后看下一项投资。
- 本店表现直接说明净赚、亏损或盈亏平衡，并用一行补充收入、毛利和顾客转化。
- 主要原因复用既有经营瓶颈，并把工资、运营成本、现金续航和当前市场事件压缩成解释文字。
- 下一项投资复用资本顾问当前第一优先级，同时显示投入、证据状态和现金压力；最近投资的完整日结比较在同一处反馈。

## 结构与边界

- 没有新增玩法系统、按钮、模拟规则或存档字段；schema 保持 v7。
- `StoreEconomyViewModel` 只格式化 Application 层已经计算的分析结果，不重新计算利润或瓶颈。
- `InvestmentPortfolioViewModel` 只投影资本顾问已经排序的方案，不拥有收益、回收期或现金压力公式。
- 删除只复制店铺导航集合的 `MarketOverviewViewModel`；街区仍负责选择店铺，经营页专注当前店铺。

## 验证证据

- 先加入经营结论、亏损/盈亏平衡、下一项投资和 XAML 精简合同，测试因缺少属性与旧界面结构失败。
- 实现后聚焦 Release 回归通过 23/23。
- 版本冻结后统一 Release 测试入口通过 699/699：Domain 102、Application 246、Infrastructure 33、Rendering 110、Desktop 196、Release 12。

## 下一步

1. 使用当前候选包进行陌生玩家首轮测试，重点观察玩家能否在不阅读长说明的情况下说出店铺赚没赚钱、原因和下一步。
2. 根据测试结果调整三段结论的文案优先级与信息密度，不先扩充新系统。
3. 若理解度达标，再评估事件短史是否确有必要；当前版本只显示正在影响经营的事件与最近一次投资对比。
