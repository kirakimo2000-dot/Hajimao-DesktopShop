# Hajimao DesktopShop 0.1.29 管理窗 UI/UX 基线

## 本阶段完成

- 使用 `ui-ux-pro-max` 建立设计基线，并按 Windows 桌面与像素游戏语境过滤掉玻璃模糊、霓虹泛光、联网像素字体和移动端导航建议。
- 扩充共享颜色令牌，统一管理窗背景、卡片、悬停、焦点、主要操作、成功、警告和文字层级。
- 新增共享页标题、眉题、卡片、主导航、辅助按钮和像素滚动条样式；窗口不再散落临时十六进制颜色。
- 主导航和关键按钮至少 44 像素高，焦点框改为高对比实线；右栏先显示唯一下一步，再显示场景对象详情。
- 管理窗最小尺寸保留主内容与右栏安全宽度，并彻底禁用三个内容页的横向滚动。

## 范围约束

- 只修改 `HajimaoDesktopShop.Desktop` 的主题与 `ManagementWindow.xaml`，以及 Desktop UI 测试。
- 未修改 Domain、Application、Infrastructure、经营 ViewModel、命令、存档 schema 或模拟时间。
- 未启动、显示或操控本地游戏窗口；视觉检查使用内存排版与离屏 PNG。

## 验证证据

- 新增色彩对比度、共享令牌、焦点样式、44 像素目标、最小尺寸、右栏顺序和离屏渲染测试。
- 失败测试先暴露缺失令牌、36 像素按钮、右栏优先级和未主题化滚动条，实现后聚焦测试通过 24/24。
- 离屏快照确认导航、三段经营结论、下一步卡片和深色像素滚动条层级清晰；临时快照不进入仓库。
- 版本冻结后统一 Release 测试入口通过 709/709：Domain 102、Application 246、Infrastructure 33、Rendering 110、Desktop 206、Release 12。
