# v0.1.30 完整 UI/UX 收口

日期：2026-08-14

## 完成内容

- 将首店选择、桌面街区、具体店铺和经营窗口统一到暖色深色像素设计系统。
- 首店选择先说明这是“第一笔投资”，每张卡固定展示赚钱方式、主要风险和适合对象；选定动作保持单一明确。
- 桌面街区保留一店一宽、随开店横向增长、永久置顶、拖动吸附和鼠标穿透行为；新增最短操作提示，扩大关键控件命中区。
- 经营页继续只暴露概览、策略、投资三项；策略选中态取自当前真实投影，右栏继续只强调一个下一步。
- 所有 Desktop 组件 XAML 清除主题字典外的原始十六进制色；正文最小 12 像素，主要操作最小 44 像素。
- 新增可选离屏快照工具，覆盖首店、街区 WPF 覆盖层、店内覆盖层以及经营三页；运行过程中不显示窗口、不操作用户光标。

## 验证证据

- UI 聚焦门禁：36/36 通过（首店、桌面、主题、经营窗口和策略投影）。
- 离屏视觉检查：首店对比卡、经营概览、经营策略、投资决策均完成 1180×720 或页面目标尺寸检查。
- 六测试项目统一入口：711/711 通过（Domain 102、Application 246、Infrastructure 33、Rendering 110、Desktop 208、Release 12）。首次解决方案命令只执行 Desktop 且发现版本契约仍指向 0.1.29；同步为 0.1.30 后通过项目统一入口完成发布候选验证。

## 已知边界

- WPF 离屏渲染不会触发 Skia 场景控件的 Loaded 生命周期，因此桌面离屏图只验证 WPF 覆盖层；像素场景本体继续由 Rendering 专项测试验证。
- 桌面场景的四个透明热区没有常驻文字，依靠场景自身图标、工具提示、键盘焦点和辅助技术名称，避免遮挡挂机画面。
- 本版没有修改任何经营收益、客流、库存、员工、投资、时间或存档规则。

## 下一步计划

- 先收集真实测试反馈，重点观察首次启动选择耗时、是否理解点击店铺进入、能否识别当前策略和投资优先级。
- 只有出现重复反馈时才继续调整 UI 文案或布局；下一玩法版本优先补可玩内容与长期数值，不新增运营面板。
