# v0.1.33 首局核心循环阶段报告

日期：2026-08-14  
分支：`feature/v0.1.33-core-loop`

## 本阶段目标

让新玩家选完首店后立即看到小店持续运转，在首份经营报告前获得可理解的成交反馈，并把需要经营证据的投资决策延后到报告形成之后。本阶段不扩充管理系统，也不恢复离线收益或倍速。

## 已完成

- 程序运行时店铺持续经营，不存在游戏内日期、钟点、开门等待、关店空转或早晚高峰。
- 桌面街区显示最近活动、首轮 5 单进度和当前短目标。首笔成交后会明确显示距离首轮店况还差多少单。
- 首局引导改为“先让小店运转起来”：店型推荐方案默认生效，玩家无需先进入策略页完成设置。
- 首份经营报告前可以查看投资成本和预期，但不能执行；形成真实收入、成本和利润后才开放候选投资。
- 保留固定现实 1x：后台每累计 1,440 个活跃运行 Tick 形成一份经营报告；程序关闭期间没有收益。

## 底层边界

- 价格、服务、队列、整洁度和事件继续影响需求；早晚时段加成已从需求公式删除。
- 员工持续在岗，后台自动处理工作负荷、体力和工时费，不再使用钟点决定是否工作。
- 旧存档及既有内部结构中的 `GameMinute`、`Day` 命名仅作为兼容字段与报告周期标识保留，不再具有日期、钟点或时段含义，也不参与客流、排班或开关店判断。
- 首轮 5 单是既有成交快照的显示里程碑，不发放额外货币或资源。
- 投资门禁位于桌面交互层，执行时仍会通过既有 Application 命令重新校验资金和条件。

## 玩家首局路径

1. 选择一种首店经营形态。
2. 回到街区观察自动经营、最近活动和首轮 5 单进度。
3. 首轮成交形成后继续挂机，等待首份经营报告。
4. 在经营页查看收入、成本、利润和主要原因。
5. 基于真实结算选择第一笔投资，然后回到街区验证效果。

## 下一步

0.1.34 聚焦街区与店内两级界面的结构重做：强化首屏视觉引导、把经营结果和下一步行动放到稳定位置，并减少解释性文字。该阶段只重构表现和交互，不新增后台管理系统。
