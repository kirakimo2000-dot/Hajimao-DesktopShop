# v0.1.6 管理前端与桌面交互阶段总结

日期：2026-08-04

## 本阶段结果

- 正式 WPF 组合根改为创建或恢复 `BusinessSession`，后台每个现实秒只调用一次 `AdvanceRealSecond`。
- 新存档从街角便利店起步，等级继续解锁商品和后续店铺；三家店铺目录通过不可变快照提供给前端。
- 管理窗口完成店铺、商品、进货、员工、成长、财务、商业街七区单列导航，实时像素小店和运营摘要不随页面切换消失。
- 商品页接入每次 ¥0.10 调价；进货页接入本地、区域、厂家三渠道和 25%/80% 自动补货策略。
- 员工页接入招聘、培训、跨店调配、08:00–16:00 白班和 17:00–01:00 夜班。
- 成长页接入扩建、货架、装修和三类促销；财务页分列营业收入、采购、毛利、工资、运营成本与净利润。
- 桌面窗口使用完整经营快照渲染，并提供打开管理、锁定、穿透和静音右键菜单。
- 桌面与管理窗口均保持 `ShowInTaskbar=False`；通知区域继续提供恢复和明确退出。

## 架构与产品约束

- WPF ViewModel 只负责选择、格式化、刷新和命令转发；资金、等级、容量、工资、升级与促销规则仍位于 Domain/Application。
- 页面持有稳定的商品/员工卡片，不在刷新时重复创建领域对象。
- 游戏时间只展示“固定现实 1x”；代码和界面都没有暂停、2x、4x 或速度选择入口。
- 商业街本阶段只展示已开店与路线预告，没有提前实现 0.1.8 的共享街道模拟。
- 存档 schema 保持 v6，避免仅因前端迁移产生无意义的数据迁移。

## 与原需求的差距

- 已补齐：一家店起步、等级解锁店铺/商品、不同商品毛利、不同员工效率/工时费、多店开设、固定现实 1x、托盘常驻、模块化管理前端。
- 当前像素角色、货架和商品为程序化几何，不是最终 Sprite 资产；正式资产、动作和定制音效属于 0.1.7。
- 商业街当前是预告与已开店列表；共享客流、车辆、天气和收起状态栏属于 0.1.8。
- 新手引导、平衡与长时稳定验收仍属于 0.1.9。
