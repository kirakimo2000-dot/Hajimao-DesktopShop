# v0.1.7 正式像素资产、动画与音效阶段总结

日期：2026-08-04

## 本阶段结果

- 建立 `256×256 RGBA` 单图集，包含收银员、补货员、顾客各 4 帧，环境/冷藏/冷冻货架各 1 帧，以及与 `products.json` 顺序一致的 10 个商品图标。
- `PixelSpriteAtlas` 只从 Rendering 程序集的固定逻辑资源名加载图集，并提供不可变帧区域；图集尺寸、透明像素和 256 KiB 上限由测试锁定。
- `BusinessShopSceneRenderer` 改用最近邻采样绘制货架、商品、员工和顾客；库存状态保留绿/黄/红短条，最多显示 5 位排队顾客。
- 表现帧与经营时间解耦：管理窗每 250 ms 刷新表现，桌面单窗每 2 秒刷新；`AdvanceRealSecond` 仍是唯一经营推进入口。
- Windows“减少动态效果”关闭时播放 4 帧短动作，开启时所有角色固定第 0 帧；没有增加动画开关、暂停或倍速。
- 八类经营反馈改为程序生成的 22,050 Hz、16-bit、单声道 RIFF/WAVE 芯片提示，每个提示不超过 16 KiB，并继续受静音状态控制。
- 通知区域改为 32×32 Hajimao Market 像素店面图标；图标句柄、`NotifyIcon`、菜单、音频流和播放器均有明确所有权与释放路径。
- 管理窗实时场景增加“实时像素店铺场景”自动化名称；桌面和管理窗口继续不出现在普通任务栏。

## 资产管线与来源

- 使用 OpenAI 内置图像生成于 2026-08-04 创建项目专用源图，没有引用第三方游戏素材包。
- 角色提示统一要求右向三分之四视角、同脚底基线、同像素密度和四等分帧：待机、轻微重心变化、岗位/行走动作、回稳。
- 货架提示要求同透视的环境木架、青色冷藏柜和蓝色冷冻柜；商品提示按 5×2 固定网格生成矿泉水、牛奶面包、杯面、海盐薯片、鲜牛奶、橘子汽水、火腿三明治、草莓酸奶、香草冰淇淋和速冻饺子。
- 所有源图使用纯 `#ff00ff` 色键且禁止主体使用洋红；构建器从边界清除相连色键噪点、逐格保留最大主体、最近邻缩放并底部居中。
- 仓库只保留运行时图集、文档预览、来源 README 和可复用构建器；原始生成图和色键工作图已移出工作树。
- 正式图集：`src/HajimaoDesktopShop.Rendering/Assets/PixelArt/market-atlas.png`。
- 预览：`docs/assets/v0.1.7-market-atlas-preview.png`。
- 构建器：`tools/pixel-assets/build_market_atlas.py`。

## 架构与产品约束

- Rendering 只读取 `BusinessShopSceneFrame`、不可变快照和表现帧，不持有或修改资金、库存、等级、工资、需求或存档状态。
- 图集区域、资源预算和角色上限集中在 `Rendering.PixelArt`；Desktop 只负责窗口刷新、系统动态偏好、音效输出和托盘生命周期。
- 经营继续固定现实 1x；没有恢复原型的暂停/2x/4x，也没有用表现动画改变挂机收益。
- 存档 schema 保持 v6；本版本没有领域模型、经济公式或迁移变化。
- 图集编码大小为 38,063 字节，低于 256 KiB；八类 PCM 提示均低于 16 KiB。

## TDD 与验证证据

- 动画契约先因 `AnimationFrame`、`ReduceMotion` 和资源预算类型缺失进入 RED，再实现只影响表现层的帧推进。
- 图集测试先因 `PixelSpriteAtlas` 缺失进入 RED，再实现嵌入资源、固定区域和透明像素验证。
- 场景测试先因不同表现帧输出相同进入 RED，再实现最近邻精灵渲染、减少动态效果和五位顾客上限。
- 无障碍测试先因实时场景缺少自动化名称进入 RED，再补齐 XAML 标注并确认没有动画/倍速控件。
- 音效与托盘测试先因声音库和图标工厂缺失进入 RED，再实现确定性 PCM 与品牌图标所有权。
- `dotnet test HajimaoDesktopShop.slnx -c Release --no-restore --nologo`：215/215 通过；Domain 60、Application 90、Infrastructure 17、Rendering 10、Desktop 38。
- `dotnet build HajimaoDesktopShop.slnx -c Release --no-restore --nologo`：0 警告、0 错误。

- Desktop 程序集版本为 `0.1.7.0`；图集为 256×256/38,063 字节；八类音效为 4,012–9,304 字节；schema 保持 6。
- 静态发布检查确认两处 `ShowInTaskbar=False`、零动画/暂停/倍速按钮命中、零工作区临时/备份/数据库/日志杂项。

- 合并前审阅要求把图集尺寸/字节预算从“仅测试资产”提升为运行时加载硬校验；错误尺寸和超预算资源现在会在绘制前以诊断异常拒绝，补货员、顾客和三类货架也加入可见像素覆盖。

## 与原需求的差距

- 已补齐原需求中的正式人物/货架/商品像素表现、短促反馈音、托盘品牌图标、任务栏隐藏、固定现实 1x 和减少动态效果边界。
- 角色当前是岗位/排队用的 4 帧短循环，没有完整的进店、逐货架移动、拿货、结账、离店逐段动画；这属于后续场景深化。
- 商业街仍是管理页预告和已开店列表；共享街道、路人、车辆、天气、昼夜与收起状态栏属于 0.1.8。
- 场景对象点击、完整新手引导、商业平衡、长时间挂机与混合 DPI 多显示器矩阵验收属于 0.1.9。
- Serilog 仍未形成正式的异常/模拟日志管线；本版本没有为视觉资产阶段扩大基础设施范围。
