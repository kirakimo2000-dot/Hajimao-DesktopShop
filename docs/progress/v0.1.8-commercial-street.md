# v0.1.8 商业街 Beta 阶段总结

日期：2026-08-04

## 本阶段结果

- 商业街从管理页预告升级为真实经营系统：玩家等级在 Lv.1、Lv.3、Lv.5、Lv.10 分别解锁街角、相邻店铺、一段商业街和完整街区。
- 正式等级曲线从 6 级补齐到 10 级，Lv.7～Lv.10 阈值为 2,000/3,200/5,000/7,500 经验，完整街区不再是不可达展示状态。
- 每六个经营小时按固定序列切换晴朗、多云、雨天和大风；天气直接修正共享街道客流，不通过 UI 或渲染器改变收益。
- 多店 Tick 改为“两阶段”：先逐店结算工资、清洁和收银，再从同一街道人流中按店铺吸引力加权分配至多一名访客。
- 多开店铺为共享街道提供最多 30% 的客流协同，但新增人流仍在店间竞争，不会复制到每家店。
- `CommercialStreetSnapshot` 公开街区阶段、天气、共享客流、可见路人/车辆、逐店吸引力与客流份额；所有集合均为只读快照。
- 新增 420×160 独立 Skia 商业街渲染器：五个固定铺位、最多六名路人、两辆车和雨/风环境层，复用正式顾客 Sprite 与最近邻采样。
- Windows“减少动态效果”开启时街道路人固定第 0 帧；表现帧刷新不会推进经营时间。
- 管理窗商业街页面显示实时街景、天气、共享客流和逐店份额；底部状态栏可从 56 像素收至 34 像素。
- 桌面窗和管理窗继续 `ShowInTaskbar=False`；通知区域仍是恢复与明确退出入口。

## 模块边界与存档

- `Domain.Streets` 只包含等级、天气、整数交通倍率与可见环境预算，不引用 Application、WPF、SQLite 或 SkiaSharp。
- `Application.Business.Street` 接收显式店铺需求输入并使用注入的随机源路由访客；它不读取窗口或 renderer 对象。
- `BusinessSimulation` 是唯一将共享路人转化为店内访客、库存选择和结账队列的入口；离线批量结算继续调用同一 `AdvanceRealSeconds` 管线。
- Rendering 只读取 `CommercialStreetSceneFrame`；Desktop 只负责中文文本、动画帧、状态栏命令和 WPF 组合。
- 街区、天气和可见角色均由玩家等级、经营分钟与经营快照派生；累积到店人数继续保存在现有逐店运行状态，因此 schema 保持 v6，不需要伪造新的迁移。
- 单店保留原有一次到店随机判定顺序；多店才增加一次整数权重选择，确保从一家起步的既有存档不因纯结构重构改变随机消费顺序。

- Domain RED：测试先因 `Domain.Streets`、天气和街区类型不存在而编译失败；GREEN 后覆盖 21 个等级、天气、倍率、预算和非法输入用例。
- Application RED：测试先因商业街服务/快照缺失而编译失败；GREEN 后验证单店随机序列、多店共享上限、权重路由、天气快照和严格保存恢复等价。
- Rendering RED：测试先因商业街 frame/renderer 缺失而编译失败；GREEN 后验证店铺、车辆、雨滴像素、四帧变化、减少动态效果和 6/2 角色上限。
- Desktop RED：测试先因商业街 ViewModel/控件、状态栏命令和属性缺失而编译失败；GREEN 后验证中文摘要、表现帧、真实控件自动化名称与展开/收起状态。
- 初次全量回归发现旧多店测试仍要求每家店同分钟各产生一名顾客；该断言与新共享客流规则冲突，改为验证所有店完成员工处理、总客流最多一名。

## 独立代码审阅

- 审阅未发现 Critical；发现 Important：商业街阶段原先只用于展示，快照声明的阶段可能容纳不下已经开设的店铺。
- 根因是店铺开设权限本就属于 `ShopDefinition`/`RetailBusiness`，商业街服务没有店铺定义，不能重复判断解锁合法性。首次尝试在 Application 按玩家等级直接拒绝时，五个合法的通用多店测试出现回归；追踪职责后改为由原有店铺定义继续作为唯一开店门槛，商业街阶段取“玩家等级阶段”和“容纳已开店铺所需阶段”中的较高者。
- Domain 统一提供阶段与铺位容量的双向规则；Application 保证所有领域层已开店铺都能进入快照，Rendering 则拒绝店铺数超过快照声明阶段的真正损坏状态。
- 审阅后自检同时发现正式 `LevelCurve` 最高只有 Lv.6；已先用失败测试复现，再补齐至 Lv.10，确保完整街区真实可达。
- Minor 文档与本地化问题一并修正：Changelog 使用 Release 口径，逐店百分比固定使用 invariant culture。
- 修复后复审结果为 Critical 0、Important 0、Minor 0；审阅者额外执行 Domain 30、Application 4、Rendering 4、Desktop 4 项相关 Release 测试并确认 ready to merge。

## 与原始桌面需求的差距

- 已兑现商业街按等级逐段开放、玩家多店可视化、共享客流、路人、车辆、天气和可收起状态栏。
- 遵守原始范围限制：其他商店只作为街景背景，不模拟其内部经营，也没有扩张成完整开放城市。
- 店内顾客仍缺逐货架路径、拿货、结账和离店的完整分段动作；商业街店面及人物当前不能直接点击选择。
- 当前天气为确定性轻量周期，没有节庆、道路施工、事故等长期街道事件。
- 新手教程、最终数值平衡、长时稳定、安装包、混合 DPI/负坐标多显示器矩阵和正式 Serilog 管线仍未完成。
