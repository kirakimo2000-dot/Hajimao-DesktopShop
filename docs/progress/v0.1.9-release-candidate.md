# Hajimao DesktopShop 0.1.9 发布候选报告

日期：2026-08-05
平台：Windows 10 2004+，win-x64，自包含 .NET 10；MSI 按机器安装并请求管理员权限
存档：SQLite schema v6，兼容 v1～v5 逐级迁移
节奏：固定现实 1x，无暂停、倍速或离线加速捷径

## 完成范围

- 七步无状态新手任务与管理页引导，进度只由真实经营快照推导。
- 生产离线结算、结构化滚动日志、生命周期故障降级、长时经营审计和平衡/兼容回归。
- 纯几何多显示器放置策略、Win32 工作区枚举和 PerMonitorV2 进程契约。
- 项目级 WiX 6.0.2 MSI、win-x64 自包含便携 ZIP、SHA-256/JSON 清单和安全构建脚本。
- 真实便携/MSI 进程验收：响应、SQLite、日志、任务栏样式、安装、卸载和数据保留。

本阶段没有扩展经营公式、UI 页面或存档字段；玩家等级、多店、商品毛利、员工效率/工时费、离线同管线与固定现实 1x 保持不变。
