# Hajimao DesktopShop 0.2.11 新档成长阶段

## 取证结果

- 旧版本三类开局首次招待为 33～54 秒，但便利店首次随机掉落最迟达到 268 秒。
- 新档现金为 ¥1,200，第二家便利店投入 ¥800 且仍能保留推荐储备，开局即可扩张。

## 本阶段改动

- 首位成功招待必定从该顾客掉落表中解锁一个尚未拥有的商品；普通掉率、精通和后续随机表不变。
- 新品使用独立战斗提示和五秒桌面提示，并把唯一下一步指向经营页装备。
- 新档现金调整为 ¥200。旧存档继续读取已保存现金，不被重置。
- 新店页面以正数显示资金缺口，并说明只有实际运行游戏才产生收入。

## 验证结果

- 便利、折扣、精品开局首次招待和新品分别出现在第 33、33、54 秒。
- 便利店第二店在确定性发布基准第 16,145 秒首次可负担，约 4 小时 29 分。
- 新品战斗反馈截图确认“招待成功”与“解锁新品！”具有独立层级。

## 下一步

不新增页面，集中改进商品替换前后的数值比较，并在顾客信息中只暴露最关键的弱点或抗性提示。
