# Hajimao DesktopShop 0.2.7 共用人类人物模型阶段

日期：2026-08-18

## 本阶段目标

在不改变战斗数值和经营规则的前提下，解决顾客像僵尸、街道与店内人物割裂，以及普通/致命受击反馈位置异常的问题。

## 已完成

- 新增独立的 `HumanCharacterRenderer` 与 `HumanCharacterVisualCatalog`，作为街道和店铺共用的人物表现入口。
- 街道路人与店内顾客统一使用 `humanoid-v1` 骨骼、`maomao-default` 皮肤、毛毛模块化部件图和 24 帧动作资源。
- 删除旧顾客全身色彩调制及其专用配饰渲染器；肤色、头发和身体保持原始人类色彩，差异仅来自比例、配饰和局部强调色。
- 街道场景异步加载共用人物资源，离开页面时会取消加载并释放位图，避免阻塞 UI 或泄漏资源。
- `ProductHitEvent` 保存目标最后的千分位位置；目标在致命一击后已离场时，反馈仍能回到真实命中点。
- 普通受击数字根据当前插值姿态的头部骨骼定位，不再使用固定 Y 坐标；成功招待反馈也复用对应命中位置。

## 已知缺口

- 目前所有角色仍共享毛毛基础人体；这解决了风格割裂和异常染色，但角色多样性仍主要依赖比例与配饰。
- 后续需要在同一骨骼/槽位规范下增加正常人类的独立头部、发型与服装部件，而不是重新引入整人滤色或第二套人物系统。
- 本阶段只修复人物模型和战斗反馈，不调整收益数值、顾客刷新或 UI 信息层级。

## 下一步

1. 精简店铺 HUD，突出当前威胁、挂机收益、招待结果和掉落。

3. 按共用骨骼槽位扩充正常人类头部、发型和服装资源，并维护资源许可清单。
