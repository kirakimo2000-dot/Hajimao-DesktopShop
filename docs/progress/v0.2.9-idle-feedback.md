# Hajimao DesktopShop 0.2.9 挂机反馈阶段

## 本阶段目标

不增加新玩法系统，只解决店铺页“看不懂在做什么、收益不明显、缺少继续挂机理由”的体验问题。

## 已完成

- 店铺页底部固定为两行：本次收入与战果统计、当前状态或唯一下一步提示。
- 本轮收入按启动时快照计算；每次招待以差量显示实际新增现金，反馈至少保留三秒。
- 无战果时说明顾客会自动进入；战斗中说明击败顾客获得现金与商品；已有掉落后提示进入经营页装备。
- 店内战斗将成功招待和掉落改成跟随最后命中位置的文字反馈。
- 清除旧指标叠字，并调整现金位置避开返回按钮。

## 边界

- 未改变战斗、收益、掉落、顾客池、存档或多店算法。
- 未增加任务列表、强制教程、游戏内时间、倍速或离线收益。
- 街区页仍只保留现金、本次收入与特殊事件，不显示任务信息。

## 下一步

用真实新存档进行第一轮 15～30 分钟试玩，记录首次掉落时间、首次装备理解成本和第一次开新店的等待感；只根据实际节奏问题调整管理页层级和数值反馈。
