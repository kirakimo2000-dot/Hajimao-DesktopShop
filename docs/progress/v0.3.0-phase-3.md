# v0.3.0 阶段总结：确定性模拟引擎

## 完成内容

- 建立暂停、1x、2x、4x 速度和现实秒到游戏分钟的确定性映射。
- 建立可批量推进、受锁保护的模拟入口，适配后台运行与低活跃批量结算。
- 顾客完整经过进入、寻找商品、排队、结账和离开，每 Tick 最多切换一次状态。
- 收银员以 FIFO 队列处理结账，销售结果真实修改资金、库存和财务累计。
- 补货员以 FIFO 队列执行玩家任务，领取与完成分 Tick 展示，失败原因进入场景快照。
- 场景快照仅包含不可变数据记录，不向 UI 或 Rendering 暴露可变 Domain 对象。
