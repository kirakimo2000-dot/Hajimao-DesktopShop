# v0.4.0 阶段总结：可玩双窗口

## 本阶段结果

Hajimao 已从无界面的模拟核心升级为可真实操作的 WPF 桌面游戏。小窗持续展示经营状态，管理窗可完成进货、调价和速度控制；两者共享同一份不可变场景快照，经营规则仍留在 Domain/Application。

## 已完成

- 420×280 透明无边框桌面小店：置顶、拖动、角落吸附、锁定、鼠标穿透和双击展开。
- 1180×720 经营管理窗：10 种商品、补货、调价、员工状态、财务、缺货警告与暂停/1x/2x/4x。
- 深色暖调像素界面令牌、键盘焦点、可访问名称以及双窗口共用场景。
- `GameViewModel` 只发送 Application 命令并消费只读快照；代码后置仅负责窗口系统行为。
- 可取消后台模拟循环和固定种子随机适配器。
- 修复只读 `Run.Text` 绑定崩溃、Topmost 遮挡和速度假高亮。
