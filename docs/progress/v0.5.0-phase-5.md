# v0.5.0 阶段总结：存档与像素表现

## 本阶段结果

Hajimao 现在具备可持续游玩的桌面游戏基础：经营现场每 5 秒自动写入 SQLite，退出时强制刷新；重启可连续恢复资金、财务、库存、售价、时间、速度、顾客和员工任务。双窗口场景已统一切换到独立 SkiaSharp 像素渲染器。

## 已完成

- Application 版本化存档契约（schema v1）和完整模拟状态捕获/恢复。
- SQLite v0→v1 幂等迁移、事务 upsert、窗口位置表和未来版本保护。
- 自动保存并发合并、退出强制刷新、屏幕内窗口位置与锁定状态恢复。
- 420×180 逻辑像素 SkiaSharp 渲染：三类货架、库存标记、柜台、员工、顾客和状态色。
- 整数缩放、禁用抗锯齿，同一渲染器复用于桌面窗与管理窗。
- 补货、调价、成交音效事件，可替换系统输出，支持管理窗静音。
