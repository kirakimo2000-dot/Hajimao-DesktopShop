# v1.0.0 第一阶段完整可玩 Demo

## 交付结果

Hajimao 1.0.0 已形成可独立运行的 Windows 桌面便利店 Demo：桌面角落持续经营，管理窗可进货、调价和切换速度，顾客与员工完成真实经济闭环，SQLite 连续恢复现场，SkiaSharp 提供统一像素表现。

## 完整玩法闭环

1. 新局以 ¥500.00 启动，补货员领取初始补货。
2. 玩家可为 10 种商品安排补货并按 ¥0.10 调整售价。
3. 顾客进店、选货、排队，由收银员结账并离店。
4. 库存、现金、采购支出、收入和毛利同步更新。
5. 暂停/1x/2x/4x 改变经营节奏。
6. 每 5 秒和退出时保存完整现场，重启继续经营。
