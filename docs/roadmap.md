# 正式版本迭代路线

正式版本从 `0.1.0` 开始。此前交付统一归档为原型历史。每个版本必须可构建、可验证，并同步更新 `CHANGELOG.md`、`docs/progress/`、下一阶段计划和工作区清理记录。

正式发布前的当前路线统一使用 `0.1.x` 补丁版本递进，避免把单个底层模块误标为新的次版本；只有成熟发布时才进入 `1.0.0`。

开发顺序遵循：`玩法底层 → 模拟与经济 → 挂机与自动化 → 内容 → 前端/UI → 商业街 → 1.0`。

| 版本 | 阶段目标 | 可验证交付 |
| --- | --- | --- |
| 0.1.0 | 玩法底层 | 固定现实 1x；玩家等级；商品/店铺解锁；多店共享资金；商品毛利；员工效率/工时费；托盘常驻 |
| 0.1.1 | 多店模拟与经营深度 | 多店同时 Tick；价格/需求/服务/队列/整洁度；工资结算；日结与净利润 |
| 0.1.2 | 挂机与存档 | 真实离线批量结算、回归报告、多店/员工完整存档和兼容迁移 |
| 0.1.3 | 采购与自动化 | 三采购渠道、配送时间、最低采购量、自动补货、缺货策略 |
| 0.1.4 | 员工经营 | 招聘、排班、培训、体力、满意度、导购与清洁岗位 |
| 0.1.5 | 单店成长内容 | 货架位、面积、装修、促销、相邻店铺扩建和升级曲线 |
| 0.1.6 | 管理前端 | 真实导航页面、商品/员工卡片、桌面对象交互、右键快捷菜单和可访问性 |
| 0.1.7 | 正式像素表现 | 角色动作、商品/货架 Sprite、正式音效、动画与资源预算 |
| 0.1.8 | 商业街 Beta | 底部商业街、多店可视化、共享客流、路人/车辆/天气和收起状态栏 |
| 0.1.9 | 发布候选 | 平衡、教程、完整回归、兼容存档、安装包和长时稳定性验收 |
| 1.0.0 | 正式发布 | 平衡、教程、完整回归、兼容存档、安装包和长时稳定性验收 |

## 当前 0.1.6 边界

- 正式 WPF 已运行 `BusinessSession`，管理页只通过 Application 命令和不可变快照操作经营状态。
- 七区导航覆盖店铺、商品、进货、员工、成长、财务与商业街预告；同一时刻只展开一个内容面。
- 桌面 420×280、管理窗 1180×720；两者不创建普通任务栏按钮，通知区域负责恢复和退出。
- 游戏固定现实 1x，不存在暂停、倍速或速度选择；挂机收益只能通过经营、自动化与成长改善。
- schema v6 必须逐级迁移 v1～v5；不得丢失旧资金、库存、采购、员工或运行时状态。
- 0.1.7 只升级正式 Sprite、角色动作、定制音效和资源预算，不把经营规则移入渲染层。

## 每阶段出口条件

1. 新行为有明确失败测试，并完成 RED → GREEN → REFACTOR。
2. 完整 solution Release 构建无警告/错误，所有测试通过。
3. NuGet 漏洞检查无已知漏洞。
4. Changelog 与版本阶段报告包含完成项、证据、遗留和下一步。
5. 只保留源文件、必要配置、确认资产和正式发布物。
