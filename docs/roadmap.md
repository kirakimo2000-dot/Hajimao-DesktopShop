# 正式版本迭代路线

正式版本从 `0.1.0` 开始。此前交付统一归档为原型历史。每个版本必须可构建、可验证，并同步更新 `CHANGELOG.md`、`docs/progress/`、下一阶段计划和工作区清理记录。

开发顺序遵循：`玩法底层 → 模拟与经济 → 挂机与自动化 → 内容 → 前端/UI → 商业街 → 1.0`。

| 版本 | 阶段目标 | 可验证交付 |
| --- | --- | --- |
| 0.1.0 | 玩法底层 | 固定现实 1x；玩家等级；商品/店铺解锁；多店共享资金；商品毛利；员工效率/工时费；托盘常驻 |
| 0.2.0 | 多店模拟与经营深度 | 多店同时 Tick；价格/需求/服务/队列/整洁度；工资结算；日结与净利润 |
| 0.3.0 | 挂机与存档 | 真实离线批量结算、回归报告、多店/员工完整存档和兼容迁移 |
| 0.4.0 | 采购与自动化 | 三采购渠道、配送时间、最低采购量、自动补货、缺货策略 |
| 0.5.0 | 员工经营 | 招聘、排班、培训、体力、满意度、导购与清洁岗位 |
| 0.6.0 | 单店成长内容 | 货架位、面积、装修、促销、相邻店铺扩建和升级曲线 |
| 0.7.0 | 管理前端 | 真实导航页面、商品/员工卡片、桌面对象交互、右键快捷菜单和可访问性 |
| 0.8.0 | 正式像素表现 | 角色动作、商品/货架 Sprite、正式音效、动画与资源预算 |
| 0.9.0 | 商业街 Beta | 底部商业街、多店可视化、共享客流、路人/车辆/天气和收起状态栏 |
| 1.0.0 | 正式发布 | 平衡、教程、完整回归、兼容存档、安装包和长时稳定性验收 |

## 当前 0.4.0 边界

- 当前 WPF 画面只保持兼容，不扩建正式页面。
- 三渠道采购、在途配送和自动补货先形成 Domain/Application 能力与测试。
- 在线 Tick 与离线结算必须调用同一采购推进入口，不实现伪倍速。
- schema v4 必须逐级迁移 v1/v2/v3；不得丢失旧经营数据或已付款订单。
- 下一阶段只扩展员工经营底层，正式采购与员工页面仍留到 0.7.0。

## 每阶段出口条件

1. 新行为有明确失败测试，并完成 RED → GREEN → REFACTOR。
2. 完整 solution Release 构建无警告/错误，所有测试通过。
3. NuGet 漏洞检查无已知漏洞。
4. Changelog 与版本阶段报告包含完成项、证据、遗留和下一步。
5. 只保留源文件、必要配置、确认资产和正式发布物。
