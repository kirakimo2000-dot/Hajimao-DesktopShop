# Hajimao DesktopShop 路线图

## 已完成：0.2.0 核心重构

- 主循环从补货销售改为“自动投掷商品 → 清空顾客需求 → 现金与商品掉落”。
- 账号共享商品图鉴、重复掉落精通、逐店 3～6 格装备和多店独立战斗。
- 现实本地时段与运行事件驱动顾客池，无游戏内时间、离线收益和倍速。
- 单背景店内场景、24 帧骨骼动作、插值移动、命中/收益/掉落反馈。
- 新店三选一扩张与店型风险收益差异。
- schema v8、旧存档迁移、365 阶段确定性长期运行与单文件便携包。

## 0.2.x：先把可玩体验做实

1. 已完成：校准首分钟引导、首个商品掉落、客流波动、命中节奏和第二家店投资时间。
2. 已完成：街道按真实店铺无限扩宽、8 类建筑轮廓、逐店点击路由、全局店员与装备占用。
3. 下一步：增加装备替换前后对比和顾客关键弱点提示，不增加新的管理页面。
4. 下一步：把占位内饰逐店替换为统一像素风背景，并完善顾客视觉差异。
5. 后续：扩充商品、顾客和事件数据，同时保持全部资源可达、单 EXE 和快速启动。

## 0.3.x：角色与长期构筑

- 在毛毛之外加入可收集角色；不设置职业，角色通过自身数值、动作和特殊效果区分。
- 角色获取可采用抽取机制，但必须复用现有通用战斗属性、骨骼与皮肤边界，不能改写核心引擎。
- 增加跨店构筑、稀有顾客、事件链与长期收藏目标，避免高频点击和重复维护。

## 设计约束

- 桌面挂机是真正的收益来源；不做离线收益、倍速或游戏内时钟。
- 玩家精力用于少量投资与构筑判断，不用于补货、排班或大量运营表单。
- 新系统优先合并到现有三页，不因底层模块增多而增加菜单。
- 版本只在完整验证、更新日志和最新可运行文件同时就绪后发布。
- 每个大阶段总结完成项、验证结果、遗留风险和下一步；小修改不单独写报告。
