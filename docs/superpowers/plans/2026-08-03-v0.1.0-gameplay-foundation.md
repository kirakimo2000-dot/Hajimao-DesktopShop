# v0.1.0 Gameplay Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebase Hajimao at 0.1.0 and deliver a tested gameplay-first foundation for fixed-time operation, player progression, product/store unlocks, multiple stores, differentiated product economics, employee efficiency/wages, and tray-only Windows presence.

**Architecture:** Domain owns player, level curve, shared business wallet, store portfolio, products and employees. Application exposes a business service and immutable snapshots; the current single-store WPF UI remains an adapter and is not expanded. The existing prototype save is migrated compatibly while player speed is removed across all active contracts.

**Tech Stack:** .NET 10, C# 14, WPF, CommunityToolkit.Mvvm, SQLite, System.Text.Json, xUnit.
