# Hajimao v0.3.0 Offline Persistence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist and restore the complete multi-store business runtime, migrate SQLite saves from schema v2 to v3, and settle bounded offline time through the same deterministic tick pipeline used online.

**Architecture:** Keep persistence contracts in Application, domain rehydration inside Domain, and JSON/SQLite migration inside Infrastructure. A `BusinessSession` composes business state, simulation runtime, stateful randomness, and save capture; `OfflineSettlementService` only computes a safe elapsed duration and delegates every applied second to `BusinessSimulation.AdvanceRealSeconds`.

**Tech Stack:** .NET 10, C# records, xUnit, Microsoft.Data.Sqlite, System.Text.Json, WPF compatibility shell.

---

## File structure

- `Application/Persistence/GameSaveData.cs`: schema v3 root and legacy-compatible fields.
- `Application/Persistence/BusinessSaveData.cs`: player, stores, products, employees, queues, active checkout, day baselines, random state.
- `Application/Business/BusinessSession.cs`: create/restore/capture composition boundary.
- `Application/Business/Simulation/BusinessSimulation.cs`: runtime rehydration and complete state capture.
- `Application/Business/Offline/*`: elapsed-time policy, settlement result, and tick-pipeline settlement service.
- `Application/Simulation/IStatefulRandomSource.cs`: state capture/restore contract without Infrastructure coupling.
- `Infrastructure/Simulation/DeterministicRandomSource.cs`: serializable deterministic PRNG.
- `Infrastructure/Persistence/LegacyGameSaveV2.cs`: exact schema-v2 payload reader.
- `Infrastructure/Persistence/SqliteGameSaveStore.cs`: transactional v2→v3 migration.
- Domain `Employee`, `Shop`, and `RetailBusiness`: explicit validated rehydration only; no JSON or SQLite references.
