# Hajimao Market v0.1.6 Management UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Windows 桌面程序正式运行 `BusinessSession`，并以像素风管理窗口呈现多店、商品采购、员工、成长促销与财务能力。

**Architecture:** Desktop 组合根创建或恢复一个 `BusinessSession`，后台循环只调用固定现实 1x 的 `BusinessSimulation.AdvanceRealSecond`。`MarketViewModel` 只组合按功能拆分的页面 ViewModel；页面通过 Application 命令和不可变快照更新，不复制经营公式。Rendering 新增面向 `BusinessSimulationSnapshot` 的聚合像素场景，保留旧原型渲染器作为 schema v1 兼容代码但不再由正式 App 启动。

**Tech Stack:** .NET 10、C# 14、WPF、CommunityToolkit.Mvvm、SkiaSharp、SQLite schema v6、xUnit。

---

## Locked product and visual direction

- 游戏幻想：暖色夜间便利店像素模型，像一件放在桌面角落持续运转的电子摆件。
- 视角：桌面窗口为轻微侧视角小店；管理窗上方保留实时场景，页面信息从下方和右侧渐进展开。
- 核心动作：切换/开设店铺、调价和采购、自动补货、招聘/培训/排班、扩建/货架/装修、启动促销、阅读经营日报。
- HUD：桌面窗口只常驻金币、玩家等级、顾客/队列和库存告警；管理窗为顶部状态、左侧单列导航、中央内容、右侧运营摘要与底部高频动作。
- 材质与字体：深炭色像素面板、2px 硬边、暖黄主色、绿/红状态色；标题使用 `Microsoft YaHei UI`，数字使用 `Consolas`，不使用模糊阴影或圆角 SaaS 卡片。
- 动效：只为导航切换、命令成功/失败和重要告警保留短促状态变化；尊重系统减少动画设置，不做持续微动效。
- 窗口：管理窗口 `1180×720`、最小 `960×640`；桌面窗口 `420×280`；两者始终 `ShowInTaskbar=False`，退出仍经通知区域。
- 游戏时间固定现实 1x；管理界面不显示暂停、倍速或速度选择。
- 商业街在 0.1.6 只显示路线预告和已开店列表，不提前实现 0.1.8 的共享街道模拟。

- [x] **Step 3: Implement composition-only content and session factory**

`DesktopGameContent` exposes three immutable shop definitions (`corner-store` level 1/free, `station-store` level 3/¥800, `community-store` level 5/¥2,000), a six-level curve `[0, 40, 120, 300, 650, 1_200]`, and starter cashier/restocker assignments. `DesktopBusinessSessionFactory.Create` calls `BusinessSession.Create` for a new game or `BusinessSession.RestoreOrUpgrade` for schema v6, using `DeterministicRandomSource` and never altering simulation speed.

```csharp
public static BusinessSession Create(
    IReadOnlyList<ProductDefinition> products,
    GameSaveData? save,
    int seed)
{
    var random = new DeterministicRandomSource(seed);
    return save is null
        ? BusinessSession.Create(products, DesktopGameContent.Shops,
            DesktopGameContent.LevelCurve, "corner-store", 50_000,
            DesktopGameContent.CreateStarterAssignments(), random)
        : BusinessSession.RestoreOrUpgrade(products, DesktopGameContent.Shops,
            DesktopGameContent.LevelCurve, "corner-store", save,
            DesktopGameContent.CreateStarterAssignments(), random);
}
```
