# Hajimao Market v0.1.7 Pixel Assets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用正式像素图集、克制的角色动画、定制芯片音效和品牌托盘图标替换 0.1.6 的程序化人物/系统占位反馈，同时保持完整经营会话、固定现实 1x 与低资源桌面常驻。

**Architecture:** Rendering 内嵌一个只读 `256×256` PNG 图集，由 `PixelSpriteAtlas` 按显式帧区域提供最近邻绘制；`BusinessShopSceneRenderer` 仍只消费不可变 `BusinessShopSceneFrame`，动画帧由 Desktop 的展示时钟提供，不进入存档或经营 Tick。Desktop 使用纯展示的 `PixelGameSoundBank` 合成短促 PCM WAV，并用 `TrayIconFactory` 生成品牌像素图标；Domain/Application/Infrastructure 和 schema v6 均不改变。

**Tech Stack:** .NET 10、C# 14、WPF、SkiaSharp、System.Drawing、System.Media、CommunityToolkit.Mvvm、xUnit、Python/Pillow（仅资产构建）、built-in image generation、game-studio sprite pipeline。

## Locked visual, motion and resource direction

- 幻想：暖色夜间便利店电子摆件；轻微侧视角、深炭背景、暖黄灯箱、低饱和环境、高亮人物与商品。
- 图集：最终运行时只保留 `Assets/PixelArt/market-atlas.png`，固定 `256×256 RGBA`，不运行时扫描文件夹，不从 WPF 读取松散图片。
- 角色：收银员、补货员、顾客各一条 4 帧横向动画；单帧 `32×40`，共享底部中心锚点，面向右侧，帧 1 锁回种子姿势。
- 店内物件：常温、冷藏、冷冻三种 `64×56` 货架；十种 `16×16` 商品图标；缺货继续使用红色图标加文字语义。
- 动画：管理窗刷新时最高 4 FPS；桌面独处时保持 0.5 FPS 低功耗。减少动画开启时固定种子帧，不影响模拟。
- 反馈：销售、采购、调价、员工、成长与警告只使用短促帧变化或 80–220 ms 芯片音，不做循环背景音乐、持续粒子或界面抖动。
- 预算：图集不超过 256 KiB；单个合成 WAV 不超过 16 KiB；场景同时显示顾客最多 5 人；Skia 全程最近邻、无抗锯齿。
- 兼容：正式图集加载失败时抛出可诊断异常，不静默退回占位人物；旧 `ShopSceneRenderer`/`DesktopShopRenderer` 保留给原型兼容测试。

- [x] **Step 3: Implement deterministic feedback audio and icon ownership**

`PixelGameSoundBank` writes mono 16-bit PCM at 22,050 Hz with a valid RIFF header. Cues last 80–220 ms and use deterministic square/triangle envelopes mapped by feedback kind. `PixelGameSoundOutput` caches `MemoryStream`/`SoundPlayer` per kind and disposes them. `TrayIconFactory` draws a no-smoothing 32×32 dark shop with warm awning, lit window and green open pixel, clones the HICON, and releases the native handle. `TrayIconService` accepts or creates the icon and owns its disposal.
