# Hajimao Market v0.1.8 Commercial Street Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a deterministic commercial-street simulation that shares pedestrian traffic across opened stores, exposes weather/vehicle/pedestrian snapshots, renders the street in the management window, and provides a collapsible status bar without adding speed controls.

**Architecture:** Domain owns pure street progression and traffic factors. Application routes at most one shared passerby to an opened store per fixed one-minute tick and publishes immutable street snapshots; persisted store visitor totals remain the source of truth, so schema v6 stays compatible. Rendering consumes snapshots only, while Desktop owns presentation text, commands, accessibility, and WPF composition.

**Tech Stack:** .NET 10, C# 14, WPF, CommunityToolkit.Mvvm, SkiaSharp, xUnit, SQLite schema v6.
