# v0.1.9 Logging and Stability Implementation Plan

> **Execution:** Use `executing-plans` task by task in the current worktree. Every behavior change follows RED → GREEN → REFACTOR.

**Goal:** Make real desktop startup apply capped offline progress, add a structured rotating-file diagnostics boundary, and produce deterministic long-run multi-store audit reports without coupling Domain to logging or UI.

**Architecture:** Desktop remains the composition root. Application owns immutable diagnostic and audit contracts plus the existing offline policy; Infrastructure adapts diagnostic events to Serilog files; Domain remains unaware of clocks, files, Serilog, and WPF. Startup receives an explicit UTC timestamp, restores the saved session, settles elapsed time through the same `BusinessSimulation.AdvanceRealSeconds` pipeline, and returns both the session and settlement result. Long-run audit compares immutable snapshots around batched public simulation advances.

**Tech Stack:** .NET 10, C# records, WPF, Serilog 4.4.0, Serilog.Sinks.File 7.0.0, xUnit

## Self-review

- Requirement coverage: production startup now performs the already-designed eight-hour capped idle simulation; no speed controls are introduced.
- Coupling: Domain owns business rules only; Application owns contracts/use cases; Infrastructure owns Serilog; Desktop owns clocks, paths, and lifetime.
- Compatibility: no save-schema change is needed; settlement starts from existing schema-v6 saves and captures the same schema afterward.
- Noise/privacy: lifecycle and failures are logged, not every tick or autosave; properties are operational identifiers and numeric totals, not arbitrary user content.
- Scope: installer/portable packaging and multi-display matrix remain the next v0.1.9 substage.
