# v0.1.9 Onboarding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a fixed-1x onboarding task chain that teaches the real procurement, pricing, automation, sales, employee, growth, and multi-store systems without adding mutable tutorial state.

**Architecture:** A stateless Application projection evaluates existing immutable business, simulation, and procurement snapshots and returns stable task IDs plus completion state. Desktop maps those IDs to Chinese presentation text and management-section navigation; WPF only binds the resulting view model. Because every condition already persists in schema v6 business state, all historical saves reconstruct onboarding progress without a migration.

**Tech Stack:** .NET 10, C# records/enums, CommunityToolkit.Mvvm, WPF, xUnit

- [x] **Step 3: Implement the minimal immutable projection**

Define the stable task IDs:

```csharp
public enum OnboardingTaskId
{
    RestockProduct,
    AdjustPrice,
    EnableAutoRestock,
    CompleteFirstSale,
    TrainEmployee,
    UpgradeStore,
    OpenSecondStore
}
```

Define records with constructor validation and read-only collections:

```csharp
public sealed record OnboardingTaskState(OnboardingTaskId Id, bool IsCompleted);

public sealed record OnboardingSnapshot(
    IReadOnlyList<OnboardingTaskState> Tasks,
    int CompletedTasks,
    OnboardingTaskId? CurrentTaskId)
{
    public int TotalTasks => Tasks.Count;
    public bool IsComplete => CurrentTaskId is null;
}
```

Implement `OnboardingProgressService.CreateSnapshot(BusinessSimulationSnapshot simulation, ProcurementSnapshot procurement)` with these exact completion predicates:

```csharp
var stores = simulation.Business.Stores;
var states = new[]
{
    new OnboardingTaskState(OnboardingTaskId.RestockProduct,
        stores.Any(store => store.StockPurchaseCostCents > 0)),
    new OnboardingTaskState(OnboardingTaskId.AdjustPrice,
        stores.SelectMany(store => store.Products)
            .Any(product => product.SalePriceCents != product.ReferenceSalePriceCents)),
    new OnboardingTaskState(OnboardingTaskId.EnableAutoRestock,
        procurement.AutoRestockPolicies.Any(policy => policy.IsEnabled)),
    new OnboardingTaskState(OnboardingTaskId.CompleteFirstSale,
        stores.Any(store => store.RevenueCents > 0)),
    new OnboardingTaskState(OnboardingTaskId.TrainEmployee,
        simulation.Employees.Employees.Any(employee => employee.TrainingLevel > 0)),
    new OnboardingTaskState(OnboardingTaskId.UpgradeStore,
        stores.Any(store => store.Growth is not null
            && (store.Growth.ExpansionLevel > 0
                || store.Growth.ShelfLevel > 0
                || store.Growth.DecorationLevel > 0))),
    new OnboardingTaskState(OnboardingTaskId.OpenSecondStore, stores.Count > 1)
};
```

The current task is the first incomplete state; completion counts all completed facts even when they occur out of order. Return `Array.AsReadOnly(states)`.
