# Hajimao DesktopShop 0.1.10 Desktop Street Navigation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a content-sized, horizontally unbounded commercial street the normal desktop surface, enter an individual store interior only after clicking its storefront, and give every visible character multi-frame movement animation.

**Architecture:** Keep the simulation, economy, save schema v6, fixed reality 1x, and management window unchanged. The street content width is derived from opened storefront count with no maximum; the WPF host grows with it until the monitor work-area viewport is full, then pans an unbounded logical street. Add presentation-only street/store navigation, shared render/hit-test geometry, deterministic presentation movement, eight-frame character strips, and monitor-aware bottom docking.

**Tech Stack:** .NET 10, WPF, CommunityToolkit.Mvvm, SkiaSharp, xUnit, existing Application immutable snapshots and Rendering pixel atlas.

---

## Product decisions locked by this plan

- The desktop resident window starts and returns to **Street** mode. Store mode is transient and is not added to schema v6.
- Clicking an opened storefront changes the same desktop window to **Store** mode and selects that store as the shared management context.
- Only opened player stores occupy street length. Unopened and level-locked stores remain available in management but do not reserve invisible desktop width.
- Store mode reuses the current `BusinessDesktopShopSurfaceControl`, including employees, shelves, products, queue, status bar, lock, click-through, and management affordance.
- A visible back affordance and `Esc` return from Store to Street. Closing/hiding and restoring from the tray returns to Street, because Street is the normal desktop state.
- The separate `ManagementWindow` remains the detailed global/store management surface. Opening it from Store mode keeps the clicked store selected; opening it from the tray uses the current selected store but does not change desktop mode.
- The street docks to the bottom edge of the selected monitor's **work area**, which places it above a conventional bottom taskbar while remaining correct for side/top taskbars and multi-monitor layouts.
- The supplied reference image is a mood reference only: continuous low-rise storefront rhythm, warm windows, signs, sidewalk, pedestrians, road, and a long transparent silhouette. Do not copy or commit that image as a production asset.
- No speed, pause, or catch-up controls are introduced. Rendering/navigation must not advance simulation time.

## 2026-08-05 user override (authoritative)

- Street content has no maximum horizontal length and no five-store rendering cap.
- One opened store produces exactly one storefront-wide street. Every newly opened store appends one storefront and one inter-store gap.
- `contentWidth = 2 × StreetMargin + openedStoreCount × StorefrontWidth + max(0, openedStoreCount - 1) × StorefrontGap`.
- The host window uses `min(contentWidth, workArea.Width - 24)` only as a viewport. When content is wider, camera offset/panning reveals the remaining content; this is not a street-length limit.
- Any later example in this document that mentions fixed `960` width, five catalog slots, or rendering unopened stores is superseded by this section.
- `Cashier`, `Restocker`, and `Customer` strips expand from four to eight bottom-center-aligned frames. Frame selection and world-position movement are separate deterministic presentation calculations.
- Street pedestrians move horizontally across the full logical street. Store customers and supporting employees use bounded walk paths; the cashier remains near checkout but receives an eight-frame working loop.
- Reduced-motion mode freezes locomotion and uses frame zero without changing simulation or save data.

```csharp
public enum DesktopSurfaceMode
{
    Street,
    Store
}

public sealed class DesktopNavigationViewModel : ObservableObject
{
    private readonly Action<string> _selectStore;
    private IReadOnlyDictionary<string, StoreNavigationItemViewModel> _stores =
        new Dictionary<string, StoreNavigationItemViewModel>(StringComparer.Ordinal);
    private DesktopSurfaceMode _mode = DesktopSurfaceMode.Street;
    private string _selectedStoreId = string.Empty;
    private string _pageTitle = "街区";

    public DesktopNavigationViewModel(Action<string> selectStore)
    {
        _selectStore = selectStore ?? throw new ArgumentNullException(nameof(selectStore));
        OpenStoreCommand = new RelayCommand<string>(OpenStore);
        BackToStreetCommand = new RelayCommand(BackToStreet);
    }

    public DesktopSurfaceMode Mode
    {
        get => _mode;
        private set
        {
            if (SetProperty(ref _mode, value))
            {
                OnPropertyChanged(nameof(IsStreet));
                OnPropertyChanged(nameof(IsStore));
            }
        }
    }

    public bool IsStreet => Mode == DesktopSurfaceMode.Street;
    public bool IsStore => Mode == DesktopSurfaceMode.Store;
    public string PageTitle { get => _pageTitle; private set => SetProperty(ref _pageTitle, value); }
    public IRelayCommand<string> OpenStoreCommand { get; }
    public IRelayCommand BackToStreetCommand { get; }

    public void Synchronize(IEnumerable<StoreNavigationItemViewModel> stores, string selectedStoreId)
    {
        _stores = stores.ToDictionary(store => store.Id, StringComparer.Ordinal);
        _selectedStoreId = selectedStoreId;
        var hasOpenSelection = _stores.TryGetValue(selectedStoreId, out var selectedStore)
            && selectedStore.IsOpen;
        if (Mode == DesktopSurfaceMode.Store && !hasOpenSelection)
        {
            BackToStreet();
        }
    }

    private void OpenStore(string? storeId)
    {
        if (storeId is null || !_stores.TryGetValue(storeId, out var store) || !store.IsOpen)
        {
            return;
        }

        _selectedStoreId = store.Id;
        _selectStore(store.Id);
        PageTitle = store.Name;
        Mode = DesktopSurfaceMode.Store;
    }

    private void BackToStreet()
    {
        Mode = DesktopSurfaceMode.Street;
        PageTitle = "街区";
    }
}
```
