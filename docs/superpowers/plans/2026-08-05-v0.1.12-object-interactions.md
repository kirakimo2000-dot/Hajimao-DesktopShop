# Hajimao DesktopShop 0.1.12 Object Interactions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让玩家在具体店铺场景中直接点击三类货架或可见员工，查看只读详情并进入对应商品/员工管理页，同时保持固定现实 1x、经济规则和存档 schema v6 不变。

**Architecture:** Rendering 新增纯几何命中图和统一员工表现位置，既供 Skia 绘制也供 WPF 输入映射使用；Desktop 控件只把屏幕坐标映射为逻辑像素并发出不可变目标。`MarketViewModel` 从既有不可变经营快照构造轻量详情卡并切换管理区，窗口代码不查询仓储、不修改经营状态。

**Tech Stack:** .NET 10、C#、WPF、CommunityToolkit.Mvvm、SkiaSharp、xUnit、PowerShell、WiX 6。

---

## Scope boundaries

- 本版本包含货架/员工命中、详情卡、桌面店铺到管理窗口的跳转、管理窗口内直接点击、版本与发布物。
- 不增加暂停或倍速，不改变模拟 Tick、顾客购买、员工工资、离线结算或 SQLite schema。
- 差异化店面资产、Authenticode 证书和更多真实硬件矩阵单独进入后续版本，避免与玩法交互耦合。
