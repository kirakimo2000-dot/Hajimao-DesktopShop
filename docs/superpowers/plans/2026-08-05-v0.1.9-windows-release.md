# v0.1.9 Windows Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce reproducible unsigned Windows x64 portable and MSI artifacts for Hajimao DesktopShop 0.1.9, verify their contents and real process behavior, then complete the release-candidate GitHub workflow.

**Architecture:** A dedicated release-contract test project validates versioned packaging source without coupling it to Desktop tests. A repository-owned PowerShell orchestrator runs tests, self-contained publish, ZIP creation, project-level WiX SDK MSI build, SHA-256 generation, and machine-readable manifest generation. The MSI owns only application and Start Menu files; LocalAppData saves/logs remain outside installer ownership and survive uninstall.

**Tech Stack:** .NET 10, PowerShell 7/Windows PowerShell compatible syntax, WiX Toolset SDK 6.0.2, Windows Installer, xUnit, GitHub CLI

### Task 2: Project-level WiX MSI source

**Files:**
- Create: `installer/HajimaoDesktopShop.Installer/HajimaoDesktopShop.Installer.wixproj`
- Create: `installer/HajimaoDesktopShop.Installer/Package.wxs`

- [x] **Step 1: Create minimal WiX SDK project**

Pin the SDK and pass build properties as preprocessor constants:

```xml
<Project Sdk="WixToolset.Sdk/6.0.2">
  <PropertyGroup>
    <InstallerPlatform>x64</InstallerPlatform>
    <OutputName>HajimaoDesktopShop-$(ProductVersion)-win-x64</OutputName>
    <DefineConstants>ProductVersion=$(ProductVersion)</DefineConstants>
  </PropertyGroup>
  <ItemGroup>
    <BindPath Include="$(PublishDir)" BindName="PublishDir" />
  </ItemGroup>
</Project>
```

The WXS package uses a fixed upgrade code, `Version="$(ProductVersion)"`, `Scope="perUserOrMachine"`, `Compressed="yes"`, `MajorUpgrade`, and an embedded cabinet. Author the desktop EXE explicitly with a Start Menu shortcut, then harvest `!(bindpath.PublishDir)\**` with child `Exclude` elements for the EXE and `**\*.pdb`. Do not author LocalAppData directories or removal rules.
