# Hajimao DesktopShop 0.1.14 Character Animation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every on-screen person use one shared 24-frame animation contract, remove malformed character pixels, and reduce the shipped character-atlas storage without changing fixed-real-time 1x simulation.

**Architecture:** Rendering owns a 24-frame presentation timeline that maps three logical frames to each of eight stored key cels. Actor positions continue to advance on every presentation frame, so movement has 24 distinct timeline steps while duplicated bitmap cels are not stored. A deterministic pixel-asset optimizer removes detached fragments, validates every character cel, and converts the atlas to a compact indexed PNG; runtime loading enforces the resulting quality and byte budgets.

**Tech Stack:** .NET 10, C# 14, SkiaSharp, xUnit, Python 3.8, Pillow 7.2, WPF.
