# v0.1.18 Investment and Return Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn employees, shelves, expansion, and decoration into comparable investments with conservative return estimates, cash-pressure warnings, executable commands, and a persisted latest-investment comparison.

**Architecture:** Add a focused `Business/Investments` vertical slice in Application. A pure advisor derives quotes from immutable business/simulation snapshots; a command service revalidates a quote and delegates to the existing employee or store-growth command; a small tracker records only the latest investment per store and compares it with a later completed day. Desktop consumes immutable portfolio snapshots and owns only Chinese formatting and commands. The save format gains an optional additive investment field while remaining schema v6-compatible.

**Tech Stack:** .NET 10, C# records and checked integer arithmetic, xUnit, CommunityToolkit.Mvvm, WPF/XAML, existing JSON-in-SQLite persistence.

## Plan self-review

- **Spec coverage:** Tasks 1–2 create explainable cost/benefit/payback/cash pressure; Task 3 unifies employee and three growth routes without duplicating commands; Task 4 provides later-day comparison and save continuity; Task 5 automates candidate renewal and onboarding; Task 6 exposes one compact decision surface; Task 7 proves at least three routes and preserves fixed 1x.
- **Scope boundary:** No products, roles, art, promotions, speed controls, or new management sections are added. Open-store investment remains separate because 0.1.18 is about improving one store; multi-store pacing remains 0.1.19.
- **Persistence:** The additive optional outer save field keeps schema v6 and old payloads valid. Only the latest investment per store is retained to keep the framework small.
- **Type consistency:** `InvestmentCandidate`, `StoreInvestmentPortfolio`, `InvestmentReturnEstimate`, `InvestmentTracker`, and `BusinessSession.Investments` are the canonical names across Application, Desktop, tests, and persistence.
- **Estimate honesty:** Unknown or non-positive benefits produce no payback. Every quote exposes the observable ability change and the condition under which the estimate can fail; no aggregate score exists.
- **Placeholder scan:** The plan contains no deferred implementation steps; every behavior maps to an exact file, focused test command, implementation boundary, and commit.
