# Hajimao DesktopShop 0.1.20 Playable Demo Candidate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 0.1.19 的长期经营底层收敛成可供陌生玩家盲测的 Playable Demo Candidate：教程只教授一次完整投资闭环，多店资金能在少量候选中比较，离线返回后能读懂结果，并保证 90 个经营日后仍有真实成长路线。

**Architecture:** 所有新增判断都从现有 `BusinessSimulationSnapshot`、投资组合、日结与离线结算派生，不保存第二套任务或推荐状态。Application 只增加纯分析快照和组合查询；Desktop 只负责中文格式化、导航与像素风呈现；已有投资、策略、开店和模拟命令仍是唯一写入口。

**Tech Stack:** .NET 10、C# 14、WPF、CommunityToolkit.Mvvm、xUnit、现有 Domain/Application/Desktop 分层、Git worktree。

---

## 范围和硬边界

- 固定现实 `1x`，没有暂停、倍速、点击收益或离线倍率。
- 不增加商品、岗位、货币、任务页、登录奖励、维护按钮或新存档字段。
- 0.1.20 自动门禁全部通过后称为 “Playable Demo Candidate 1”；三轮陌生玩家盲测未取得真实证据前，不在 README、Release 或阶段报告中称为已经完成的 “Playable Demo 1”。
- 新手引导只覆盖 `观察经营 → 选择策略 → 首次投资 → 查看后续日结回报`；第二家店、第三家店和完整街区只属于长期目标。
- 投资页最多给出三个跨店资本配置方向，不恢复逐对象维护或把所有内部候选同时倾倒给玩家。

## 文件结构

- `Application/Business/Onboarding/`：只读的新手闭环证据，不持久化。
- `Application/Business/Investments/CapitalAllocation*.cs`：跨店候选的三种投资论点与不可变快照。
- `Application/Business/Offline/ReturnBriefing*.cs`：从离线结算与最新日结派生回归摘要。
- `Desktop/ViewModels/Market/`：把分析快照格式化为简短中文并复用现有命令。
- `Desktop.Tests/Progression/`：生产内容的首次闭环、重复回归和 90 日门禁。
- `docs/playtests/`：真实盲测执行协议；只记录实际观察，不生成伪造结果。
