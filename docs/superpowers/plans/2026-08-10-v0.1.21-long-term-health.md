# Hajimao DesktopShop 0.1.21 Long-Term Economy Health Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有 90 经营日 Candidate 门禁延伸到 180/365 日，证明三条投资路线不会破产、停薪或过早耗尽已有店铺成长。

**Architecture:** 继续使用生产目录、真实经营 Tick 和现有 `LongTermProgressionScenarioRunner`，不建立第二套数学模拟。测试先要求一年内持续存在投资阶段和未封顶店铺；现有扩建、货架、装潢只延长数值曲线，不增加新系统或存档字段。长期路线的测试策略按经营风格配置员工：高周转维持双员工覆盖，高毛利与现金保守允许一名同时覆盖收银和补货的员工，生产工资、需求、价格、库存、现金储备与存档逻辑不变。

**Tech Stack:** .NET 10、C# 14、xUnit、现有 BusinessSimulation/Investment/StoreDevelopment。

- [x] **Step 1: Write the failing one-year health test**

Add a theory that runs each production policy for 365 business days and records the 90, 180, and 365 checkpoints:

```csharp
[Theory]
[InlineData(LongTermProgressionPolicy.HighTurnover)]
[InlineData(LongTermProgressionPolicy.HighMargin)]
[InlineData(LongTermProgressionPolicy.CashPreservation)]
public void OneYearPolicies_RemainSolventAndContinueExistingGrowth(
    LongTermProgressionPolicy policy)
{
    var scenario = LongTermProgressionScenarioRunner.Run(policy, days: 365);
    var dayNinety = scenario.Day(90);
    var dayOneEighty = scenario.Day(180);
    var dayThreeSixtyFive = scenario.Day(365);

    Assert.All(scenario.Checkpoints, checkpoint =>
    {
        Assert.True(checkpoint.CashCents >= 0, $"{policy}: {checkpoint}");
        Assert.Equal(0, checkpoint.WagePaymentFailures);
    });
    Assert.Equal(3, dayOneEighty.OpenStores);
    Assert.Equal(3, dayThreeSixtyFive.OpenStores);
    Assert.True(dayOneEighty.Investments > dayNinety.Investments);
    Assert.True(dayThreeSixtyFive.Investments > dayOneEighty.Investments);
    Assert.True(dayThreeSixtyFive.MaximumGrowthStores < dayThreeSixtyFive.OpenStores);
    Assert.True(scenario.Checkpoints.TakeLast(30).Count(item => item.NetProfitCents > 0) >= 24);
}
```

```csharp
[Fact]
public void OneYearPolicies_PreserveDistinctSalesAndMarginTradeoffs()
{
    var turnover = LongTermProgressionScenarioRunner.Run(LongTermProgressionPolicy.HighTurnover, 365).Day(365);
    var margin = LongTermProgressionScenarioRunner.Run(LongTermProgressionPolicy.HighMargin, 365).Day(365);
    var preservation = LongTermProgressionScenarioRunner.Run(LongTermProgressionPolicy.CashPreservation, 365).Day(365);

    Assert.NotEqual(turnover.CompletedSales, margin.CompletedSales);
    Assert.True(GrossMarginBasisPoints(margin) > GrossMarginBasisPoints(turnover));
    Assert.All(new[] { turnover, margin, preservation }, item => Assert.True(item.NetProfitCents > 0));
}
```
