# Hajimao DesktopShop 0.1.21 Playtest Feedback Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让测试者从通知区域一键生成可直接回传的脱敏 ZIP，只包含版本、聚合经营状态和白名单诊断事件。

**Architecture:** Application 层的纯报告工厂只映射 `BusinessSimulationSnapshot` 的聚合数值；Infrastructure 层的读取器只从日志首行提取时间、级别和事件名，并由归档写入器创建 `feedback.json` 与说明文件。托盘服务只发出请求事件，Desktop `App` 只负责抓取一次快照、调用基础设施和反馈结果，使业务投影、文件采集、压缩和 UI 编排彼此独立。

**Tech Stack:** .NET 10、C# 14、System.Text.Json、System.IO.Compression、WPF/WinForms NotifyIcon、xUnit。
