# Hajimao DesktopShop 0.1.22 Idle Usability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Project policy requires direct execution for ordinary iterations.

**Goal:** Make the desktop surface a permanently topmost, active-runtime-only idle game while reducing the management window to one clear next action and a scrollable, uncluttered layout.

**Architecture:** Keep simulation timing in Application/Desktop session composition, window placement in Desktop services/window code, and guidance composition in Desktop view models. Remove offline and sound feature slices completely instead of leaving disabled branches; preserve save schema v6 and the real-time one-second simulation loop.

**Tech Stack:** .NET 10, WPF, CommunityToolkit.Mvvm, xUnit, SQLite save schema v6.
