# Hajimao DesktopShop v0.1.26 Starter Store Choice Implementation Plan

> **Required skill:** Use `executing-plans` to execute this plan task by task. Apply `test-driven-development` to every behavior change and `verification-before-completion` before release claims.

**Goal:** Let a new player choose one of three meaningfully different starter stores while restoring existing saves without interruption.

**Architecture:** The Application layer owns deterministic proposal generation and real format/brand economics. The Desktop layer presents three concise player-facing cards and passes the selected proposal into the session factory. The factory converts the proposal into the existing starter store instance, so current simulation, staffing, autosave, and old-save restoration remain decoupled and unchanged.

**Tech stack:** .NET 10, C#, WPF, CommunityToolkit.Mvvm, xUnit, existing JSON content catalogs and SQLite save pipeline.
