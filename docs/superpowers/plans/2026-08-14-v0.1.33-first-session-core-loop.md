# v0.1.33 First-Session Core Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a newly selected store begin meaningful operation immediately, show short active-session milestones before the first daily settlement, and prevent evidence-free investment.

**Architecture:** Keep the existing Domain and business formulas. Add an optional initial simulation minute used only by new desktop sessions, extend the existing read-only idle feedback projection with five-sale milestones and recent activity, and gate investment commands in the Desktop presentation layer until a completed business day exists. Existing save restoration, fixed real-time 1x, no-offline-income behavior, content catalogs, and renderers remain unchanged.

**Tech Stack:** .NET 10, C# 14, WPF, CommunityToolkit.Mvvm, xUnit.
