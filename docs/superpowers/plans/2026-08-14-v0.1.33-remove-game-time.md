# v0.1.33 Remove Game Time Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove clock-of-day gameplay so a running store operates continuously and no player-facing surface exposes dates, hours, shifts, dayparts, or game-time countdowns.

**Architecture:** Keep a monotonic active-runtime counter because deterministic events, autosave, investment ordering, and legacy saves require an ordering key. Remove clock semantics from new-session setup, employee availability, demand, traffic, rendering, and copy. Continue producing periodic operating reports every 1,440 active ticks, but present them as reports rather than days; retain legacy `GameMinute` save fields only for schema compatibility.

**Tech Stack:** .NET 10, C# 14, WPF, CommunityToolkit.Mvvm, SkiaSharp, xUnit.
