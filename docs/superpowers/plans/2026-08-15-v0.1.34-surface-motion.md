# v0.1.34 Surface Placement and Character Motion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep street/store surfaces fully visible during drag and navigation, simplify the street HUD, and replace erratic character motion with stable task-driven routes and correct 24-frame playback.

**Architecture:** Window geometry stays in pure placement policies; the WPF window only reads work areas and applies the returned point. Street HUD changes remain XAML-only. Rendering gains explicit movement/facing state, while business simulation remains untouched: customer journeys derive only from stable presentation frames and employee routes derive from current task plus a deterministic employee seed.

**Tech Stack:** .NET 10, C# 14, WPF, SkiaSharp, CommunityToolkit.Mvvm, xUnit.
