# Hajimao DesktopShop 0.2.12 Street Stores and Global Assignments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Make every opened store a visually distinct, independently selectable street entity with its own occupied employee and equipment assignments sourced from global warehouses.

**Architecture:** Keep the existing business portfolio as the single source of truth for opened stores and street order. Add a small combat-roster assignment model beside the existing per-store product loadouts; both enforce global exclusivity in `BusinessCombatService`. Keep facade dimensions in fixed street slots for predictable hit testing, while a rendering policy maps each store format/style to distinct roofline, sign, door, and window geometry. The existing management strategy surface exposes assignment state without reintroducing employee roles, schedules, wages, or restocking.

**Tech Stack:** .NET 10, C# 14, WPF, CommunityToolkit.Mvvm, SkiaSharp, xUnit, JSON save data.

**Session constraint:** Execute inline without subagents, Git commits, branches, or worktrees, following the user's explicit constraints.
